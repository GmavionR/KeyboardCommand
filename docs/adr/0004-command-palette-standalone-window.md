# 命令面板统一采用独立浮层窗口形态

命令面板选择统一采用单套常驻后台的独立浮层窗口（Spotlight / Raycast 风格），放弃「仅托盘时为独立窗口、主窗口显示时为页内遮罩」的双形态方案，也放弃「纯页内遮罩」方案。

应用启动时预先创建无边框、无任务栏图标、透明背景的轻量面板窗口并保持隐藏；系统热键（默认 `Ctrl+Shift+K`）触发时直接调用 `show()` 和 `set_focus()` 实现零延迟唤出；失焦或按 Escape 自动隐藏；回车执行跳转命令时将主窗口激活到前台。这样统一了用户的交互心智，免除了在 Windows 平台检测窗口遮挡与跨虚拟桌面的复杂性与脆弱性，且避免维护两套界面外壳；代价是引入了第二个 Webview 窗口及跨窗口状态同步需求。
