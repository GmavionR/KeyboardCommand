# 采用 WM_COPYDATA 作为外部程序消息激活协议

除命令行参数激活（ADR-0002）外，KbcApp 引入 Windows 原生 `WM_COPYDATA` (0x004A) 消息作为 AutoHotkey V2 等外部脚本或工具的实时消息通信通道。

外部脚本以极低延迟向 KbcApp 窗口句柄发送携带 JSON 格式指令的 `WM_COPYDATA` 消息，用于控制浮层窗口显隐、功能路径跳转或执行指定动作。与命令行重复启动转发相比，原生消息调用耗时在 1 毫秒以内且无额外进程创建开销；与本地 HTTP/WebSocket 服务相比，零端口占用且无需常驻网络监听，完全不增加额外内存与 CPU 消耗。代价是外部调用方必须运行在 Windows 平台且需要获取或广播查找 KbcApp 的窗口句柄。
