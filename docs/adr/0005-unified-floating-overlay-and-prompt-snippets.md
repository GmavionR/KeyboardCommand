# 统一复用单套独立浮层窗口以满足 40MB 内存限制

在保留命令面板独立浮层窗口（ADR-0004）的基础上，提示词快捷粘贴悬浮窗不再创建新的独立 Webview 窗口，而是统一复用该后台浮层容器，通过路由/模式状态切换呈现命令面板或提示词选择器。

Tauri 2 基于 WebView2，在 Windows 上每额外创建一个独立的 Webview 窗口均会引入约 30MB~50MB 的基础内存开销。为了恪守 KbcApp 全局内存限制在 40MB 以下的严苛红线，应用全局仅保留主窗口与一个常驻后台的独立浮层窗口。当用户通过热键、命令行或外部消息唤起时，浮层窗口按指令切换视图模式并聚焦；失焦或按 Escape 自动隐藏。代价是浮层前端路由需要管理模式切换与按键上下文隔离。
