# 文件夹复制功能：界面绘制说明

> 用途：将本说明交给 UI 绘制平台，产出 KeyboardCommand「文件夹浏览与文件上下文包复制」功能的主页面及设置弹窗稿。所有文案、产品规则和文件均使用中文记录。
>
> 规则来源：`PROJECT_REQUIREMENTS.md`、`.scratch/folder-content-copy/map.md` 和已解决票据。页面布局遵循 [issue32](../../.scratch/folder-content-copy/issues/32-folder-copy-ui-layout.md) 的确认结论；颜色、字体和图标样式可由绘图平台探索。

## 1. 绘制范围

请绘制 Windows 桌面应用内的 `/folder-copy` 功能页面，至少包括：

1. 主页面正常状态；
2. 搜索下拉结果、超过 10 条的提示、无结果和搜索异常状态；
3. 空选择、已选择文件和目录三态；
4. 大目录加载更多状态和忽略目录节点；
5. 复制失败反馈；
6. 历史记录列表、历史快照复制菜单、重读当前文件及其部分失败反馈；
7. 设置弹窗及保存、恢复默认值的状态。

默认绘图画布为 1280×800；这只是设计基准，不是硬性最小窗口尺寸。颜色、字体和图标样式由绘图平台探索，区域排列按 issue32 已确认的布局执行。

## 2. 页面信息架构

主页面按以下层级组织：

1. **顶部工具区**：页面标题、选择文件夹、最近文件夹路径下拉、当前路径、设置按钮。
2. **搜索区**：文件和文件夹路径搜索输入框及结果下拉列表，单独占一行。
3. **主工作区**：左右分栏；左侧文件树约占三分之二，右侧辅助面板约占三分之一。辅助面板通过“当前选择 / 复制历史”切换，首次进入时默认显示“当前选择”。
4. **底部操作区**：固定显示当前选中文件数量和复制按钮。

窗口变窄、左右分栏无法舒适显示时，主工作区改为“文件树 / 当前选择 / 复制历史”单面板切换；底部操作区保持可见，不使用横向滚动挤压内容。

## 3. 控件清单与交互

### 3.1 顶部工具区

- **页面标题**：“文件夹内容复制”。复制按钮使用“复制文件上下文包”。复制结果的正式术语为“文件上下文包”。
- **选择文件夹按钮**：打开系统文件夹选择对话框；成功选择后加载该根目录。
- **最近文件夹下拉框**：列出已使用过的文件夹路径；选择路径后加载该目录并恢复该文件夹最近历史记录中、仍存在且符合当前规则的文件选择。
- **当前路径文本**：显示当前根目录完整路径；空间不足时可截断显示，悬停或点击时可查看完整路径（呈现方式由图稿决定）。
- **设置按钮**：打开本功能设置弹窗。每次打开时从 SQLite 查询设置。
- 尚未选择文件夹时，主工作区显示引导用户选择文件夹的空状态。

### 3.2 搜索区

- 输入框提示文案建议：“搜索文件或文件夹路径”。
- 用户停止输入 500 毫秒后启动搜索；按大小写不敏感的纯文本包含匹配当前根目录下的相对路径。
- 结果按完整路径升序排列，最多显示 10 条。匹配多于 10 条时，在列表末尾显示“结果过多，请输入更准确的路径”。
- 空输入时不显示结果列表；有输入但没有匹配时显示“没有搜索到”。
- 每条结果显示名称、相对路径和文件/文件夹类型；文件结果可显示当前选中状态。
- 使用上下键移动高亮项，Enter 执行当前项：
  - **文件**：切换选中状态，并在树中展开祖先目录、定位和滚动到对应节点；
  - **文件夹**：只在树中展开祖先目录、定位和滚动到该目录，不切换文件夹选择状态。
- 处理结果后保留搜索列表打开，以支持连续处理多个结果。
- fd 不可用时禁用输入框，并在输入框旁提示安装 fd。遍历部分失败时显示可访问结果并提示“搜索不完整”；若没有可显示结果但存在遍历错误，也显示搜索不完整，而非普通无结果。
- 排除规则按名称匹配：不带 `/` 的规则只排除匹配文件，末尾带 `/` 的规则只排除匹配文件夹及其后代；支持 `*`，不区分大小写。搜索仅将文件夹排除规则传给 fd，文件排除规则由应用筛选文件结果。规则详情见 [issue29](../../.scratch/folder-content-copy/issues/29-file-exclusion-rules.md)。

### 3.3 文件树

- 树显示当前根目录下符合当前筛选规则的文件和目录；文件和目录使用不同图标。
- 普通文件行包含展开/选择所需的图标与选择控件。选择文件后显示明确选中状态。
- 可选择文件夹，选择时递归选择所有符合规则且不在忽略目录中的文件。文件夹选择控件显示“全选、部分选中、未选中”三态。
- 展开/折叠目录控制与文件夹选择控件应视觉区分，避免把定位操作误解为递归选择。
- 被忽略目录仍显示为目录节点，附“已忽略”标记且不可展开；不展示其后代。
- 被文件夹排除规则命中的目录仍显示为目录节点，附“已排除”标记且不可展开；不展示其后代。命中文件规则的文件不显示。
- 单个目录的直接子项数超过当前阈值（默认 50）时分批展示。首批 30 项；每次点击“加载更多”追加 30 项，最后不足 30 项时显示全部剩余项。
- 大目录尾部建议展示“已显示 N 项，共 M 项，剩余 K 项”及“加载更多”操作。显示计数的最终文案可由图稿调整。

### 3.4 当前选择区与复制操作

- 显示“已选择 N 个文件”及当前选中文件列表；列表项至少能辨认文件名，建议同时显示相对路径。
- 用户可以从树中取消选择；搜索结果中的文件也可切换选择。选择列表的每个文件项提供直接移除操作；移除后同步更新文件树及已选文件数量。无选中文件时复制按钮禁用。
- **复制按钮**（“复制文件上下文包”）：将所选文件内容生成文件上下文包并复制到剪贴板。
- 普通复制中任一文件读取失败：取消整次复制，剪贴板和历史不变；保留勾选状态，并用对话框列出失败文件路径和可获得的原因。
- 文件上下文包的准确标题、换行和分隔格式见已解决的 [issue31](../../.scratch/folder-content-copy/issues/31-copy-package-exact-format.md)。

### 3.5 历史记录区

- 全局最多 20 条；同一文件夹可以有多条。新增导致超过上限时淘汰创建时间最早的记录。
- 选择文件夹后默认筛选该文件夹的记录，并提供“当前文件夹 / 所有文件夹”切换；尚未选择文件夹时默认显示所有记录。
- 按创建时间从新到旧排列；复制已保存快照不刷新排序位置，成功重读并替换后按新创建时间排到前面。
- 每条记录建议显示复制时间、来源文件夹、纳入文件数量及文件列表预览；可查看保存的文件上下文包内容。
- 每条记录提供复制下拉操作：
  - **主按钮：复制已保存内容**。直接复制历史快照，不重新读取源文件。
  - **菜单项：读取当前文件**。按该历史记录的文件路径重新读取源文件。
  - **删除按钮**：删除这条历史记录。
- 从历史记录读取当前文件时，缺失/读取失败项不阻止其他文件继续读取，并提示失败项；至少一个文件成功时，复制成功文件组成的新文件上下文包，以新历史记录替换当前记录；全部失败时保留旧记录和剪贴板内容，只提示失败详情。
- 复制已保存快照不改变历史创建时间；成功重读并替换后使用新创建时间。
- 当前文件夹无记录时显示“此文件夹暂无复制历史”，并提供切换到“所有文件夹”的入口。全局无记录时显示“暂无复制历史记录”，提示用户选择文件夹、复制文件后历史会出现在这里。历史面板筛选不影响加载文件夹时恢复其最新记录中的选择。详见 [issue33](../../.scratch/folder-content-copy/issues/33-history-list-scope-and-order.md)。

## 4. 设置弹窗

使用一个可滚动弹窗纵向分组展示以下配置。打开时读取 SQLite；保存时写入 SQLite，并重新加载当前文件夹，使更新立即生效。

### 4.1 文件白名单

- 可编辑扩展名与特殊文件名列表，显示“添加、编辑、删除”操作。
- 默认白名单面向源码、配置、文档、脚本文本；敏感文本文件（如 `.env`、`.pem`、`.key`）没有硬编码禁用规则。
- 二进制文件不在默认白名单中。

### 4.2 文件名/路径排除规则

- 规则全局共用，且在白名单后应用。
- 提供规则列表与添加/编辑/删除控件；默认规则包含生成/锁文件模式及 `.DS_Store` 文件。
- 规则只匹配名称，在当前根目录下任意层级生效；支持 `*`，不区分大小写。不带 `/` 表示只排除匹配文件，末尾带 `/` 表示排除匹配文件夹及其后代。排除文件在树中隐藏，排除文件夹显示为“已排除”且不可展开。完整规则见 [issue29](../../.scratch/folder-content-copy/issues/29-file-exclusion-rules.md)。

### 4.3 忽略目录

- 全局共用，按目录名作用于当前根目录任意层级。
- 默认目录：`.git`、`.hg`、`.svn`、`node_modules`、`bower_components`、`target`、`dist`、`build`、`out`、`.next`、`.nuxt`、`.output`、`.vite`、`.turbo`、`coverage`、`playwright-report`、`test-results`、`__pycache__`、`.pytest_cache`、`.mypy_cache`、`.venv`、`venv`、`.pnpm`、`.cache`、`.idea`、`.vscode`、`.history`、`.gradle`。
- 用户可逐项添加或删除；此分区的“恢复默认值”只恢复忽略目录清单。
- 白名单、文件排除规则和大目录阈值也各自提供独立的恢复默认值操作；每次只重置所在分区。

### 4.4 大目录阈值

- 数字输入控件，默认值 50；当单个目录直接子项数超过阈值时启用分批加载。
- 只接受正整数。空值、零、负数或小数时在输入框旁显示错误，并禁用保存，直到输入有效。
- 保存后重新加载当前目录。

### 4.5 弹窗按钮

- **保存**：保存全部设置到 SQLite，成功后关闭弹窗并重新加载当前目录。
- **取消/关闭**：放弃本次未保存修改。
- **恢复默认值**：每个设置分区内分别提供，只恢复当前分区的默认值，不影响其他配置。
- 查询成功但没有设置记录时，显示默认设置并允许编辑。
- 查询失败时显示读取失败提示和“重试”；不显示可编辑表单，不允许保存，但允许关闭弹窗。重试成功后载入设置并启用编辑；重试仍失败则保持错误状态，主页面不变。
- 保存失败时事务回滚，保留弹窗和所有未保存修改，不重新加载当前文件夹，也不改变当前生效配置。提供“重试”和“取消”；取消会放弃草稿。
- 面向用户的错误提示使用中文说明失败操作和下一步；提供“查看详情”展开技术原因，主提示不展示堆栈或原始数据库错误。规则见 [issue34](../../.scratch/folder-content-copy/issues/34-settings-persistence-failure-feedback.md)。

## 5. 主要交互流程

### 流程 A：选择并浏览文件夹

1. 打开 `/folder-copy` 功能页。
2. 用户点击“选择文件夹”，从系统对话框选择目录。
3. 页面显示根路径，并按白名单、排除规则和忽略目录加载树。
4. 查询该根目录最新历史记录，只恢复当前规则允许且仍存在的文件选择；不能恢复的文件静默跳过。历史面板默认切换到当前文件夹记录，但其显示筛选不改变选择恢复逻辑。
5. 用户展开目录；大目录按首批 30 项及后续每批 30 项追加。

### 流程 B：搜索并定位

1. 输入路径片段；停止输入 500 毫秒后启动 fd 搜索。
2. 应用将目录忽略规则和文件夹排除规则传给 fd；返回结果后再应用文件排除规则和白名单。
3. 下拉展示最多 10 个结果；超量提示用户缩小路径。
4. 上下键选择结果并按 Enter；文件切换选中状态，目录只定位。
5. 树展开祖先目录、加载必要批次并滚动到目标节点。

### 流程 C：复制当前选择

1. 页面展示已选文件数量和文件列表。
2. 用户点击复制。
3. 所有选中文件读取成功后，生成文件上下文包，更新剪贴板并新增历史记录。
4. 任一文件失败时取消整次复制，保留选择和旧剪贴板内容，并展示失败详情。

### 流程 D：从历史记录复制或重读

1. 用户选中一条历史记录。
2. 点击主复制按钮，复制记录保存的快照；或从下拉菜单选择“读取当前文件”。
3. 重读时尽可能处理所有文件；部分成功则复制成功项并替换原记录，全部失败则保留旧记录和剪贴板。

### 流程 E：修改设置

1. 用户打开设置，页面从 SQLite 读取并呈现当前配置。
2. 用户调整白名单、排除规则、忽略目录或大目录阈值；可分别恢复各分区默认值。
3. 保存成功后写入 SQLite 并重新加载当前文件夹；重新打开弹窗能读到保存值。
4. 查询失败时显示重试入口且不允许编辑；保存失败时保留草稿、弹窗和当前页面状态。

## 6. 状态与反馈清单

请在图稿中考虑以下状态：

- 尚未选择文件夹；
- 文件夹正在加载、正常显示、空文件夹；
- fd 不可用（搜索禁用并提示安装）；
- 搜索中、无匹配、结果超过 10 条、搜索不完整；
- 无选中项、部分选择、全选；
- 大目录尚有更多项、已加载完毕；
- 普通复制成功、读取失败取消复制；
- 历史快照复制、重读部分成功、重读全部失败；
- 设置无记录时显示默认值；设置读取失败、保存失败、保存成功。

复制成功后显示短暂提示；普通复制失败使用失败详情对话框；历史重读部分成功时显示可查看失败项的提示；搜索不完整时在搜索区域显示提示并保留可访问结果。设置读取失败时显示可重试的弹窗内错误状态；保存失败时在弹窗内显示错误并保留草稿，技术原因可以展开查看。
