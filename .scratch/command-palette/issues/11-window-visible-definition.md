# 11：「有窗口正在显示」的判定口径

Type: grilling
Status: resolved
Label: ready-for-agent

## 决议

基于 [issue 10](10-presentation-form.md) 采纳「统一为单套独立面板窗口」决议，本票关于「根据窗口显示状态分流到不同形态」的矛盾已自然消解。

### 具体口径收敛

1. **唤起时无需判定主窗口状态**：无论主窗口当前是隐藏在托盘、最小化到任务栏、被其他全屏应用遮挡还是处于其他虚拟桌面，按下系统级热键均统一无条件呼出独立的命令面板窗口并获焦。
2. **跳转命令执行时的窗口恢复行为**：
   - 当在命令面板中选中并执行「跳转命令」时，调用主窗口的 `show()`、`unminimize()`（若处于最小化状态恢复）、`set_focus()`（带到前台），并通过应用内路由机制切换到目标功能路径。
   - Windows 操作系统会自动将主窗口切到当前活动屏幕前台。
3. **动作命令执行时的行为**：
   - 动作命令（如切换主题）直接触发广播或持久化生效，不强制呼出主窗口。

## Comments

- 2026-11-18：由于 issue 10 统一为独立窗口，原先用于分流两套形态的复杂窗口判定不再需要，本票据简化为跳转命令的主窗口前台恢复规范并闭环。
