# 37 - 面板窗口外框边框圆角与表面过透

Type: bug
Label: ready-for-human
Status: resolved
Blocked by: 无

## 问题

第四轮桌面验收（附真机截图）指出：

1. 透明窗口整块矩形可见：带 1px 边框与圆角的外框罩在内容外，与内部 WebUI 之间有大间距，「并不是一体的」。
2. 面板整体透明度太高：窗口本体内容看不清，反而透看到窗口底下其他窗口的内容。

## 根因

1. **外框**：Tauri 窗口 `shadow` 默认 `true`。官方文档（Window Customization / `set_shadow`）明确：Windows 上无装饰窗口启用 shadow 会得到 1px 边框并在 Win11 获得圆角，DWM 框架背景铺满窗口矩形。issue 36 之前窗口与内容同尺寸，外框被内容完全遮住；加了透明外扩边距后外框暴露（截图中的圆角矩形 + hairline 边框 + 浅色底）。
2. **过透**：`--pal-surface` alpha 0.82 + `backdrop-blur-2xl`。参考站点的半透明是叠在其自身页面背景上；桌面透明 WebView 的 backdrop-filter 无法模糊窗口背后的桌面/其他窗口，半透明等于直接透看，文字对比度不足。

## 决定与实现

1. `src-tauri/tauri.conf.json` 面板窗口加 `"shadow": false`：去掉 DWM 边框/圆角/框架底；投影改由内容自身 CSS `shadow-palette` + issue 36 的透明外扩边距承担（外扩量已覆盖投影延伸），窗口边界完全不可见，只剩内容 20px 圆角，视觉一体。
2. `src/index.css`：明暗两主题 `--pal-surface` 去掉 `/ 0.82` 改为不透明（light `oklch(99.5% 0.003 230)`、dark `oklch(22% 0.015 240)`）；`CommandPalette.tsx` 移除 `backdrop-blur-2xl`（不透明表面上无视觉作用且徒增合成开销）。其余 token、圆角、投影、列表结构不变。
3. 不引入 window-vibrancy / acrylic：OS 级亚克力在透明 WebView 上兼容性差（tauri#13859 暗色失效等），不透明表面是桌面 launcher 的稳妥主流做法。

## 验证

- `cargo check` 通过（shadow 字段合法）；`bun run build` 零错误。
- ego-browser + Tauri 桩（round-08）：cmdk 根 `backgroundColor` 为不透明 oklch（无 alpha）、`backdropFilter: none`、圆角 20px；html/body 背景均 `rgba(0,0,0,0)`（确认无 CSS 涂底，外框纯系 DWM）；窗口 768×608、过滤 768×399、失焦收敛、获焦零新增 set_size 且输入框聚焦——issue 35/36 行为回归保持。
- DWM 外框消除与不透明观感属 OS 层，需用户桌面验收。
