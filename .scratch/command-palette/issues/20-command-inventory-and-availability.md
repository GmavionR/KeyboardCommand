# 20：首版命令清单、跨页面可用性与禁用态

Type: grilling
Status: open
Label: needs-triage
Blocked by: 17

## 问题

[issue 01](01-terminology-and-v1-scope.md) 定了首版只做跳转命令与动作命令两类，并列举了候选动作，但**逐条清单没定**。需要定：

- **完整清单与显示名**：每条命令的中文显示名、英文别名、所属分类。
- **分类名称与排列顺序**：[issue 03](03-category-semantics.md) 定了分类只做分组标题，但有哪些分类、按什么顺序排还没定。候选如「页面」「操作」「外观」「设置」。
- **跨页面可用性**：在 `/prompts` 页时，folder-copy 的动作命令（选择文件夹、复制文件上下文包、打开本功能设置）怎么处理——**隐藏**、**禁用并说明原因**、还是**显示但执行时先跳转过去**？三种体验差别很大。
- **禁用态**：未选择文件时「复制文件上下文包」是禁用还是隐藏？现有页面底部按钮的做法是无选中项时禁用，面板是否沿用。
- **不可用原因是否显示**：禁用条目旁边给一句说明，还是只置灰。
- **主题命令的当前值标记**：[issue 04](04-executable-items-only.md) 定了用三条互斥命令加打勾，勾的样式与位置待定。
- **是否收录「最近文件夹」**：[issue 01](01-terminology-and-v1-scope.md) 把内容检索排除在首版外，但「最近文件夹」是**有限枚举**（最多 10 条，见 [folder-content-copy issue 49](../../folder-content-copy/issues/49-recent-folder-list.md)），可以当作静态跳转命令直接列出，不需要异步 provider。这是个边界情况，要明确算不算首版。
- **空查询时显示什么**：全部命令按分类列出，还是只显示常用几条？是否按最近使用排序（首版倾向不做，保持固定顺序）。
