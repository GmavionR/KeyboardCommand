## 决议

### 1. 首版极简预置命令清单

根据用户指导，首版不需要过多预置条目，保持精简纯粹。**「操作」分类下仅保留一个核心条目：「打开文件夹...」**。

### 2. 「打开文件夹...」的联动执行机制

- 用户在命令面板（无论主窗口处于哪个页面或隐藏在后台/托盘）选中「打开文件夹...」并回车：
  1. 命令面板调用 `hide()` 立即隐藏；
  2. 主窗口调用 `show() + unminimize() + set_focus()` 激活置前；
  3. 主窗口客户端路由切换至 `/folder-copy`；
  4. 自动触发原生系统文件夹选择对话框（`dialog.open({ directory: true })`）；
  5. 用户选定文件夹后，主页面自动加载该文件夹内容。

### 3. 未来用户自定义命令的兼容性

- 遵循 [issue 17](17-command-registry-and-route-source.md) 的动态提供者接口设计，未来在系统设置中加入“命令配置页面”后，用户配置的个性化命令（如快速打开某个指定目录、自定义脚本或常用动作）将以 `category: '自定义'` 或用户指定分类直接注入列表，与首版内置命令共用同一套显示、检索与执行机制。
