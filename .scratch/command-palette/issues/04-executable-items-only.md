# 04：首版只做执行型命令

Type: grilling
Status: resolved
Label: ready-for-agent

## 问题

参考截图的 `Styles` 分组里，条目带 `○` / `□`（单选 / 多选），右侧还挂着一个次要动作（`Open style in shadcn/create`）。这类**状态型条目**会把命令面板从「执行器」变成「设置面板」：需要回显当前值、需要决定执行后是否关闭面板、需要给次要动作单独的触发方式。

首版要不要支持这种条目？

## 答案

**首版只做执行型命令**：选中并回车 = 执行一次，然后关闭面板。

- 不做单选 / 多选控件。
- 不做右侧次要动作。
- 需要表达「当前值」时，用**多条互斥的执行型命令**代替状态控件。例如主题切换拆成三条命令（浅色 / 深色 / 跟随系统），在当前生效的那条上打勾即可；打勾只是显示，不改变它「执行一次」的语义。
