# 22：是否叠加拼音首字母匹配

Type: grilling
Status: open
Label: needs-triage

## 问题

[issue 05](05-matching-semantics.md) 定了「名称包含 + 英文别名」。调研（[issue 08](08-prior-art-research.md)）显示中国市场工具还普遍叠加**拼音匹配**：uTools 官方文档明确「支持中英文、拼音、拼音首字母搜索」，一个功能可挂 `本地搜索` / `find` / `ss` 多个指令。

命令面板要不要支持输入 `sz` 命中「设置」、`fz` 命中「复制文件上下文包」？

- **不做**：英文别名已经覆盖了「敲英文找中文命令」的需求，且零新依赖、与全项目匹配语义完全一致。
- **做**：更符合中文用户肌肉记忆，但要引入拼音库（`pinyin-pro` 月下载 180 万最流行，`pinyin-match` 2.68 万但 API 更贴合匹配场景、直接返回命中索引区间），且要决定拼音命中是否参与高亮、多音字怎么处理。

## 提问时的倾向

倾向**首版不做**。理由：命令总数不到 20 条，英文别名已足够；拼音库会引入多音字与高亮索引的复杂度，而收益在命令量小的时候不明显。等命令数量上去、或用户实际使用中提出再加。

**此倾向未与用户确认，不构成决议。**
