# 22：是否叠加拼音首字母匹配

Type: grilling
Status: resolved
Label: ready-for-agent

## 决议

**首版暂不引入外部拼音库**，仅支持「中文名称包含 + 英文别名匹配」。

### 理由与边界

1. **体量与需求匹配**：首版内置命令总数不到 20 条，纯文本中文包含结合英文别名（例如 `设置` 配 `settings` / `sz`，`切换深色外观` 配 `dark`）已完全能够满足快速检索需求。
2. **避免过度复杂化**：引入第三方拼音库（如 `pinyin-match`）会增加多音字识别、首字母匹配、繁简转换以及文本高亮切片索引计算的复杂度。
3. **后续演进路径**：保留未来随命令规模扩增而叠加拼音库的可能性，首版坚持零多余依赖与清晰匹配语义。
