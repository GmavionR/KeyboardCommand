# 39 - 窗口生命周期日志记录与设置展示

Type: task
Status: resolved
Label: ready-for-agent
Blocked by: 无

## 背景与问题

在 issue 38 中，KbcApp 引入了“后台隐藏 3 分钟自动销毁 WebView 释放内存 + 唤出时按需重建”的机制。为了方便用户和开发者直观了解和排查：
1. 窗口何时隐藏、启动倒计时、被取消倒计时；
2. 窗口何时被超时强制 destroy()；
3. 窗口因何种途径（托盘、快捷键、CLI、WM_COPYDATA、命令面板）触发重建以及重建耗时。

需要在应用中引入轻量级的日志落盘能力，并在系统设置（SystemSettingsModal）中直观呈现日志目录路径，并提供一键在文件资源管理器中打开日志目录的功能。

## 详细要求

1. **轻量级日志记录模块（Rust）**：
   - 在 `src-tauri/src/app_logger.rs` 中实现日志记录器，存储路径定位在 `app.path().app_log_dir()`（回退为 `app_data_dir().join("logs")`）；
   - 日志文件名为 `lifecycle.log`；
   - 记录生命周期关键事件：
     - `create_main_window`：主窗口首次创建或按需重建完成（记录耗时与原因）；
     - `schedule_idle_destroy`：主窗口隐藏并开启空闲倒计时；
     - `cancel_pending_destroy`：用户唤起取消销毁倒计时；
     - `destroy()` 执行：3 分钟超时触发 WebView2 销毁；
     - 托盘、单实例、快捷键、WM_COPYDATA 唤起重建流程。
   - 文件大小控制：单文件超过 2MB 时自动截断/轮转，保证极轻量。
2. **Tauri 命令与接口**：
   - `get_log_dir`：获取日志所在目录的绝对路径；
   - `open_log_dir`：调用系统资源管理器打开日志目录；
3. **系统设置页面呈现（前端）**：
   - 在 `SystemSettingsModal.tsx` 的“存储与运行时状态”区域新增“运行日志目录”展示卡片；
   - 呈现真实磁盘路径，并提供“打开日志目录”按钮，支持快捷查阅。

## 验收条件

- [x] 主窗口创建、隐藏、倒计时取消、超时销毁与按需重建时，均有带时间戳的格式化日志写入 `lifecycle.log`。
- [x] 系统设置弹窗中能正确读取并展示日志目录的绝对路径。
- [x] 点击“打开日志目录”按钮，可在 Windows 文件资源管理器中定位并打开该目录。
- [x] 所有 Rust 单元测试和前端构建编译通过，0 编译错误。
