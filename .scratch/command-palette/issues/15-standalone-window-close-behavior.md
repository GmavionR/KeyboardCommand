# 15：独立窗口形态的关闭与焦点行为

Type: grilling
Status: open
Label: needs-triage
Blocked by: 10

## 问题

[issue 06](06-overlay-open-close-behavior.md) 定的关闭行为（Escape 关闭、点遮罩关闭、焦点回到打开前元素、已有弹窗时不响应热键）是针对**页内遮罩**的。若 [issue 10](10-presentation-form.md) 确定存在独立窗口形态，这些语义都要重新定义——独立窗口没有「遮罩」可点。

需要定：

- **Escape** 是隐藏窗口还是销毁窗口？隐藏则下次唤起更快且能保留状态，销毁则每次干净但要重建。
- **失焦自动关闭**：点击面板外的任何地方（含其他应用）是否即隐藏？这是 Raycast / Spotlight 的标准行为。若采用，与「点遮罩关闭」是等价语义还是不同。
- **焦点恢复到哪**：页内遮罩是回到打开前的 DOM 元素；独立窗口则要回到**唤起前的那个应用**。Windows 上能否可靠做到。
- **执行命令后**：跳转命令要把主窗口带到前台并关闭面板；动作命令（如切换主题）执行后面板是关闭还是留着？issue 04 定的是「执行一次然后关闭」，在独立窗口下是否一致。
- **再次按热键**：面板已开时再按一次，是关闭（toggle）还是无操作？
- **「已有弹窗打开时不响应热键」怎么表述**：系统级热键由系统捕获，应用无法「不响应」。是收到后忽略、还是先关掉已有弹窗再开面板、还是把面板开在弹窗之上？
- **面板窗口是否出现在任务栏 / Alt+Tab 列表**中。
