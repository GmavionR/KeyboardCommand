# 13：唤起热键的配置、存储、冲突与失败反馈

Type: grilling
Status: resolved
Label: ready-for-agent

## 决议

1. **默认热键与冲突检验**：
   - 默认全局热键为 `Ctrl+Shift+K`；
   - 底层由 `tauri-plugin-global-shortcut` 注册。若发生系统热键冲突（被系统或其他程序占用），Rust 侧捕获该错误，不阻断主程序启动；
   - 在系统设置中如实标红呈现冲突状态：「该快捷键已被系统或其他程序占用，请更换」。
2. **持久化存储**：
   - 热键配置保存在 SQLite `settings.db` 的通用系统配置中；
   - 应用冷启动时由 Rust 侧在 setup 阶段从 SQLite 或预置配置中读取并完成注册。
3. **改键与动态生效**：
   - 用户在系统设置中录制或选择新热键后，前端通过 Tauri 命令通知 Rust 侧注销旧键并尝试注册新键；
   - 若新键注册成功，立即持久化并更新界面；若新键注册失败，回滚并提示具体失败原因。
4. **单热键策略**：
   - 首版仅支持配置单一热键，不支持多组别名热键；允许用户清空热键（不启用全局唤起）。
