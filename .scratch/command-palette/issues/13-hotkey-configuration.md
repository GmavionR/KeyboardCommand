## 问题

[issue 02](02-system-hotkey-and-invocation.md) 定了「系统级、用户可配置、默认 `Ctrl+Shift+K`」。配置这件事本身有一串未决点：

- **默认键 `Ctrl+Shift+K` 是否与 Windows 或常见应用冲突？** 尚未核实。需要注意浏览器里 Ctrl+Shift+K 是开发者工具控制台，若用户同时在用浏览器，系统级注册会不会抢走它、或者注册失败。这一条要有事实结论再定默认值。
- **配置界面放哪**：系统设置的快捷键分组（当前叫「应用内快捷键与界面行为」，接入系统级后这个分组名与说明都要改）。
- **录入方式**：按下组合键录制，还是下拉选修饰键 + 键？如何禁止录入非法组合（单键、纯修饰键、系统保留组合）。
- **存哪**：设置数据库 `settings.db`（已有 SQLite 连接）还是别处？热键注册发生在 Rust 侧启动早期，读取时机如何安排。
- **注册冲突/失败怎么反馈**：被其他应用占用时，是启动即提示、还是只在设置里标红？失败后是否回退到上一个可用热键、还是干脆没有热键但应用内仍可用？
- **改键的生效时机**：立即注销旧键注册新键，还是要求重启？新键注册失败时是否保留旧键。
- **是否允许清空热键**（不用全局热键）。
- 是否支持**多个热键**绑同一动作（首版倾向不支持）。
