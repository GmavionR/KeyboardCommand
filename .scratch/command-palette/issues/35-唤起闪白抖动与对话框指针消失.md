# 35 - 唤起瞬间空白抖动与原生文件夹对话框内指针消失

Type: bug
Label: ready-for-human
Status: resolved
Blocked by: 无

## 问题

第二轮桌面验收报告两处缺陷：

1. `Ctrl+Shift+K` 唤起命令面板的一瞬间窗口抖动：先看到空白，随后才出现内部 UI 组件。
2. 执行「打开文件夹…」弹出原生文件夹选择对话框后，鼠标指针在对话框内不可见；移出对话框（回到主窗口 WebView2 区域）指针恢复显示。

## 根因

1. **空白闪 + 抖动**：issue 34 的实现把「清空搜索 + 重挂载 cmdk（重放入场动画）」放在窗口 `focus` 事件里，即显示之后才执行。于是：
   - 入场动画 `palette-in` 从 `opacity: 0` 起步 → 显示首帧空白；
   - 上一次会话若停在过滤态（窗口高度已收敛到如 271px），显示时 Rust 按旧 `outer_size` 居中，重挂载恢复满清单后 ResizeObserver 再 `setSize(480)` → 显示后二次改尺寸 = 抖动。
   - 进一步发现：隐藏页的渲染帧被 Chromium 暂停，ResizeObserver 回调会推迟到重新显示之后，因此「把重置挪到失焦期间 + 依赖 RO 收敛高度」仍不够，必须同步量高。
2. **指针消失**：WebView2 Runtime 152 起支持 Windows「打字时隐藏指针」设置，并存在回归（MicrosoftEdge/WebView2Feedback#5687）：含 WebView2 的窗口在指针处于隐藏态时被关闭/隐藏，Win32 光标显示计数在宿主 UI 线程上残留为负，整个进程内指针保持隐藏，直到鼠标进入另一个 WebView2 区域才恢复。本应用流程恰好命中：面板输入框打字（指针隐藏）→ 回车执行「打开文件夹…」→ 面板隐藏 → 原生对话框（无 WebView2）接管鼠标区域 → 指针不可见；移回主窗口 WebView2 区域即恢复。与用户描述完全一致。

## 决定与实现

1. **重置时机前移到隐藏期间**（`src/components/palette/CommandPalette.tsx`）：
   - `blur`（失焦即隐藏）时清空 query 并 `setSession` 重挂载 cmdk，重置选中态；`focus` 时仅 `inputRef.focus()`，不再重挂载、不再重放动画 → 显示即完整 UI。
   - 删除 `palette-in` 入场动画（`src/index.css` 的 `@keyframes` 与 `--animate-palette-in` 映射一并移除）：热键launcher 业界做法（Spotlight / PowerToys Run）为即时呈现，opacity 0 起步的动画正是空白闪来源。
   - 新增 `useLayoutEffect`（依赖 `session / query / commands`）在 DOM 提交后同步 `getBoundingClientRect` 量高并 `setSize(LogicalSize(640, h))`：强制布局在隐藏页同样可用，保证窗口在隐藏期间就收敛到正确高度，Rust 显示时按已收敛的 `outer_size` 居中，无二次 resize。保留 ResizeObserver 仅作可见态补充（字体加载等），其延迟回调即使落到显示后也是同值尺寸，不产生视觉变化。
2. **禁用指针隐藏回归特性**（`src-tauri/tauri.conf.json`）：两个窗口均加
   `"additionalBrowserArgs": "--disable-features=msWebOOUI,msPdfOOUI,msSmartScreenProtection,HideCursorWhileTyping"`。
   - `HideCursorWhileTyping` 为 #5687 评论中社区确认的 workaround（另见 #5708）；禁用后打字不再隐藏指针，回归无从触发。
   - 保留 wry 默认三个 disable 项：wry 的自定义 args 会整体覆盖默认值（`wry-0.57.1/src/webview2/mod.rs` `create_environment`），漏写会重新启用 mini menu / SmartScreen。
   - 两窗口字符串必须一致：共享同一 data directory 的 Webview 环境要求 browser arguments 相同（tauri-utils 配置文档警告）。
   - 不采用「锁定 Runtime 151」方案（影响所有用户且不可持续）。

## 验证

- `bun run build`（tsc + vite）零错误；`cargo check` 通过（校验 conf 新字段）。
- ego-browser + Tauri API 桩实测（round-04 / round-05 脚本，记录 `set_size` 调用序列）：
  - 满清单 8 条 / 480px；过滤「文件」2 条 / 271px；
  - 失焦后 150ms 内：query 清空、8 条恢复、根节点重挂载、`set_size` 已回 480（隐藏期间收敛成立）；
  - 获焦后：根节点身份不变（零重挂载）、输入框聚焦、**新增 set_size 调用为 0**（零二次 resize）；「外观」过滤→失焦→获焦重复循环同样零 resize；
  - 底部「唤起」热键 chip 回归正常；Esc 隐藏正常；截图视觉与 issue 34 对齐无回归。
- 指针修复属 OS / WebView2 层，浏览器桩不覆盖：需用户桌面验收（面板打字→回车打开文件夹→对话框内指针应可见）。
