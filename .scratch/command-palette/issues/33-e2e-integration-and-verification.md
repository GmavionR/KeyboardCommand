# 33：端到端集成与桌面多场景验证

Type: task
Status: ready-for-agent
Label: ready-for-agent

## 要构建什么

在真实 Windows 桌面环境下对命令面板全套功能进行端到端集成验收，覆盖全部 12 条用户故事，验证多显示器定位、全局热键 Toggle、失焦退出、输入法中文检索、打开文件夹跨页联动以及跨窗口主题同步；确保 `cargo test --lib`、`cargo check`、`bun run build` 零错误通过。

## 详细交付要求

1. **全套用户故事场景回归**：
   - 用户故事 1：全局热键在任意第三方软件处于前台时，稳定居中唤出；
   - 用户故事 2：点击外部或按 Esc 瞬间隐藏，焦点回到第三方软件；
   - 用户故事 3：面板打开时再按热键 Toggle 关闭；
   - 用户故事 4：跳转命令正常切换路由并激活前台；
   - 用户故事 5：在任意位置执行「打开文件夹...」，主窗口置前切路由并弹出文件夹选择框加载；
   - 用户故事 8：主题切换自身即时变色且主窗口无刷新同步；
   - 用户故事 9：中文拼音打字组字无误触；
   - 用户故事 10：点主窗口 × 隐藏至托盘，左键/右键菜单正常；
   - 用户故事 11：热键冲突时系统设置标红提示；
   - 用户故事 12：既有 `SearchBar` 输入法缺陷已彻底修复；
2. **多显示器与高 DPI 回归**：
   - 将鼠标置于不同显示器，验证面板是否稳定在鼠标所在屏幕的水平居中偏上位置弹出；
3. **代码健康与构建门禁**：
   - 运行 `cargo check`；
   - 运行 `cargo test --lib`；
   - 运行 `bun run build`（`tsc && vite build`）；
   - 确保全工程无遗留编译报错、类型错误或死类警告。

## 验收条件

- [ ] 全部 12 条用户故事场景在 Windows 桌面环境中手动验证通过。
- [ ] 规格说明书 [`spec.md`](../spec.md) 中的所有验收标准 100% 达成。
- [ ] `cargo check`、`cargo test --lib`、`bun run build` 全部零错误零警告通过。
