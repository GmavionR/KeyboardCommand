# 34 - 命令面板体验修订：热键自定义、弹窗 Esc、参考站点视觉与底部热键提示

Type: task
Label: ready-for-human
Status: resolved
Blocked by: 无

## 问题

首轮桌面验收后提出四项修订：

1. 系统设置中命令面板唤起 / 收起热键仅展示硬编码 `Ctrl + Shift + K`，用户无法修改（Rust 侧 `update_palette_shortcut` / `reset_palette_shortcut` 已存在但无前端入口）。
2. 系统设置弹窗与文件夹复制功能设置弹窗均不支持 Esc 关闭。
3. 命令面板列表使用浏览器默认滚动条（观感差），整体视觉与参考站点 <https://always-ready-command-hub.lovable.app/> 差距明显。
4. 命令面板底部未展示当前唤起热键，不利于肌肉记忆。

## 决定与实现

1. **热键自定义**：`SystemSettingsModal.tsx` 热键行改为动态读取 `get_shortcut_status`；新增「修改」按钮进入录制态（捕获阶段拦截 keydown，修饰键 + 主键成立即提交 `update_palette_shortcut`，Esc 取消录制），新增恢复默认按钮（`reset_palette_shortcut`）。主键名由 `e.code` 映射（`KeyK→K`、`Digit1→1`、`Space`/`ArrowUp`/`F5` 等键盘码原样），与 global-shortcut 插件解析口径一致；无修饰键或不支持主键时如实提示并继续录制；注册失败沿用既有标红冲突提示。监听 `palette-shortcut-changed` 事件跨窗口同步。
2. **Esc 关闭弹窗**：两个设置弹窗各加 window keydown 监听（`Escape` 且非 `defaultPrevented` 且非输入法组字 `isComposing` 时 `onClose()`）。录制热键时 Esc 由捕获阶段 `preventDefault + stopPropagation` 优先取消录制，不关弹窗。
3. **视觉对齐参考站点**（取代 issue 21 的部分视觉决定，匹配语义与琥珀高亮保留）：
   - 设计 token 落入 `src/index.css`（`:root` / `.dark` 的 `--pal-*` oklch 变量 + `@theme inline` 映射）：冷灰蓝表面、半透明 + `backdrop-blur-2xl`、20px 圆角、三层投影（顶部内高光 + 大软投影 + 1px 描边环）。
   - 列表项改为参考站点结构：h-11 圆角行、选中态左侧 3px 品牌色指示条、size-7 图标块（选中反转为品牌色底）、分类弱化前缀「页面 ·」「外观 ·」、右侧按键 chip；跳转标记改用 `CornerDownLeft`。
   - 滚动条改 `.palette-scroll`：`scrollbar-width: thin` + 透明轨道 + 主题色滑块（webkit 6px 圆角），取代默认长滚动条。
   - 入场动画 `palette-in`（160ms 上浮 + 缩放），每次窗口获焦重挂载重放。
   - 窗口高度随内容紧凑包裹：ResizeObserver 监听面板根节点，`setSize(LogicalSize(640, h))`；高度取 `contentRect.height`（不受入场动画 transform 影响）；列表上限 382px 使满清单总高恰为窗口配置的 480px。点击面板外透明区域直接隐藏。
4. **底部热键提示**：底部指引条右侧常驻当前唤起热键 chip 组 + 「唤起」文案，读取 `get_shortcut_status` 并跟随 `palette-shortcut-changed` 实时刷新。

## 验证

- `bun run build`（tsc + vite）零错误通过；Rust 无改动。
- ego-browser + Tauri API 桩（`__TAURI_INTERNALS__` invoke/event 模拟）桌面浏览器实测：
  - 面板满清单 8 条、列表可滚动（506 > 382）、窗口 setSize 480；过滤「文件」后 2 条、琥珀高亮 2 处、setSize 271；
  - 方向键切换选中、回车执行后隐藏、Esc 隐藏；暗色切换后 `html.dark` 与 ✓ 标记正确；明暗截图与参考站点逐元素对齐；
  - 系统设置录制 `Ctrl+Alt+P` 成功写入并刷新 chip；录制中 Esc 仅取消录制（两次复测）；恢复默认回 `Ctrl+Shift+K`；组字期 Esc 不关弹窗、普通 Esc 关闭；功能设置弹窗 Esc 关闭。
- 真实全局热键注册、托盘与多显示器场景仍由用户桌面验收（浏览器桩不覆盖 OS 层）。
