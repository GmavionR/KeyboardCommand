# 42：复制文件上下文包

**要构建：** 用户能预览并复制当前选择的文件上下文包，也能从树中右键单独复制一个文件；复制写入系统剪贴板并立即显示对应历史记录。历史记录的持久化和管理由后续票据完成。

**阻塞于：** [完成文件选择与选择清单](40-file-selection-and-summary.md)

**状态：** ready-for-agent
**标签：** ready-for-agent

**设计来源：** `playground/KeyboardCommand_Folder_Copy/docs/design.md` 的复制栏、预览弹窗和单文件右键交互是当前基准；包格式与失败规则见 `.scratch/folder-content-copy/spec.md`，并取代 issue 31 的旧格式决定。

- [ ] 按当前设计生成完整 Markdown 包：包含文件数、生成时间、来源根目录、文件清单及文件内容区块；内容完整、路径与语言标记正确。
- [ ] 预览显示即将复制的包；“复制文件上下文包”按钮及 `Ctrl+Shift+C` 写入系统剪贴板并给出成功反馈。
- [ ] 仅可选文件节点显示右键菜单“仅复制当前文件”；复制单文件并新增一条历史，不改变已有选择集合。目录、忽略节点和不可选文件不显示该菜单。
- [ ] 普通复制任一文件读取失败时全量取消，保留剪贴板和选择，并显示失败路径及可获取原因；剪贴板写入失败时也不创建成功历史。
- [ ] 成功复制后在当前运行时历史列表中新增记录；历史跨重启持久化由“持久化并管理复制历史”票据完成。
- [ ] 空选择或正在读取时主复制按钮禁用；执行时显示加载状态。
- [ ] 逐条完成前，先运行 `ego-browser skill` 并用 ego-browser 检视 playground 复制栏、预览和右键菜单；对照设计稿后，在桌面应用中手动验收多文件复制、读取失败、剪贴板反馈及单文件复制无副作用。
