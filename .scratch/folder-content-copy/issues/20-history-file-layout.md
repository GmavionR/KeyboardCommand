# 决定每条复制历史使用一个还是两个文件

Type: grilling
Status: resolved

## 问题

每条历史记录使用一个文件保存正文和元数据，还是用两个文件分别保存？结合直接查看/复制历史内容、读取列表元数据、原子写入及维护成本，选择最简单且可靠的文件布局。

## 答案

每条历史记录使用两个文件，并通过同一记录标识配对：一个 `.meta.json` 文件保存记录标识、创建时间、来源文件夹、纳入的文件列表及正文文件名；一个 `.md` 文件只保存完整文件上下文包正文，不混入元数据或转义正文内容。

新增记录时，先完整写入正文文件，再写入元数据文件；元数据文件代表该记录已完整发布。若写入中断，清理没有对应元数据的正文文件。删除记录时先删除元数据，再删除正文；残留正文由清理流程移除。替换历史记录时，先完成新记录的文件对，再删除旧记录的文件对。选择依据和一致性约束见 [ADR 0003](../../../docs/adr/0003-history-sidecar-files.md)。
