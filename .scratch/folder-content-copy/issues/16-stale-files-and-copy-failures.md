# 定义历史恢复及文件变化或读取失败时的行为

Type: grilling
Status: resolved

## 问题

如果历史选择中的文件已删除、改名或无权读取，或者复制过程中某个已选文件无法读取，目录树、历史界面和复制结果应如何反馈？明确是否允许部分复制成功、如何显示失败，以及是否自动清除已失效的选择。

## 答案

- 历史记录中的文件列表仅作为恢复当前选择的参考，不是必须同步的硬性状态。恢复时只选择路径相同、仍存在且符合当前筛选规则的文件；无法恢复选择的文件静默忽略，不显示幽灵节点，也不提示用户。
- 从当前目录发起普通复制时，任一已选文件读取失败就取消整次复制。提示失败文件的路径及可获得的原因，保留当前勾选状态供用户处理或重试；剪贴板和历史记录均不更新。
- 从历史记录复制时使用下拉按钮：默认操作复制该记录中保存的文件上下文包，不重新读取源文件；另一个选项按该历史记录的文件路径重新读取当前源文件。
- 重新读取当前源文件时，缺失或读取失败的文件不阻止其他文件继续处理，并向用户提示失败项。至少有一个文件读取成功时，将成功文件组成新的文件上下文包并复制到剪贴板；删除当前选中的历史记录，再新增一条只包含成功文件的新历史记录。
- 重新读取时若所有文件都缺失或读取失败，则不更新剪贴板、不删除或新增历史记录，并提示失败项。
- 复制保存的历史快照不会刷新其创建时间。重新读取当前源文件并成功生成新记录属于替换操作，新记录使用新的创建时间。
