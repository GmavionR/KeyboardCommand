# 41：接入实时搜索与树键盘导航

**要构建：** 用户能搜索当前目录中的可选文件和目录、定位到树节点，并用键盘完成搜索及文件树导航。

**阻塞于：** [浏览真实目录并加载文件树](38-directory-tree-and-pagination.md)、[持久化文件规则设置](39-persist-file-rules.md)、[完成文件选择与选择清单](40-file-selection-and-summary.md)

**状态：** ready-for-agent
**标签：** ready-for-agent

**设计来源：** `playground/KeyboardCommand_Folder_Copy/docs/design.md` 的键盘表格与搜索交互是当前基准；此处行为替代旧 issue 22 和 issue 36 中与之冲突的决定。

- [ ] 使用用户自行安装的 `fd` 搜索；覆盖 fd 默认跳过的隐藏/忽略项，再应用当前目录规则。fd 不可用时禁用搜索并显示安装指引。
- [ ] 按大小写不敏感的相对路径纯文本匹配；输入停止 500 毫秒后查询，最多显示 10 项，超出时提示缩小搜索；匹配部分高亮，无结果显示空状态。
- [ ] 遍历部分失败时保留已有搜索结果并提示搜索不完整；`Ctrl+F` 聚焦搜索并选中已输入文本。
- [ ] 搜索结果上下键移动高亮；Enter 对文件切换选择并保持列表开启，对目录只定位、展开并滚动到可见位置。
- [ ] 文件树上下键只移动焦点、不改变选择；Space 和 Enter 对文件夹展开/关闭、对文件切换选择；右键展开或进入首个子项，左键折叠或跳到父目录；忽略目录不能展开。
- [ ] 逐条完成前，先运行 `ego-browser skill` 并用 ego-browser 检视 playground 搜索栏及文件树键盘交互；对照设计稿后，在桌面应用中手动验收 fd 可用/不可用、部分失败、结果定位和各键盘行为。
