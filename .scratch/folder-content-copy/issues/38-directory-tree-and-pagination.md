# 38：浏览真实目录并加载文件树

**要构建：** 用户能从已接入的页面选择、输入或重载 Windows 目录，并浏览真实文件树；目录筛选及大目录分页按默认规则生效。

**阻塞于：** [初始化桌面应用并接入现有页面](37-application-shell-and-ui.md)

**状态：** ready-for-agent
**标签：** ready-for-agent

**设计来源：** `playground/KeyboardCommand_Folder_Copy/docs/design.md` 是页面 UI 与交互的当前基准；默认筛选细节见 `.scratch/folder-content-copy/spec.md`。

- [ ] 文件夹选择器、手动输入路径并按 Enter 加载、Esc 还原编辑、复制当前完整路径、最近 10 个目录选择和重新载入均作用于真实文件系统。
- [ ] 文件夹树显示真实的文件与目录；仅显示符合默认白名单及排除规则的文件，忽略或排除目录按设计标记且不能展开。
- [ ] 每个目录按直接子项数量独立判断分页；超过默认阈值 50 时，展开加载首批 30 项，加载更多追加下一批，末批显示剩余全部。
- [ ] 空目录、无可选文件、失效路径及可读取目录内容时提供与设计一致的状态和反馈；界面不再使用假目录数据作为运行结果。
- [ ] 逐条完成前，先运行 `ego-browser skill` 并用 ego-browser 检视 playground 对应页面和交互；对照设计稿后，在桌面应用中手动验收本票据的目录选择、加载、刷新和分页流程。
