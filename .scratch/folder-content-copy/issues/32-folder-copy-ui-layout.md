# 确定文件夹复制页面的控件布局

Type: grilling
Status: resolved

## 问题

产品操作规则已有较完整决定；本票据记录用户确认的主页面、历史记录和设置弹窗布局、信息层级及控件分区，供 [界面绘制说明](../../../docs/design/文件夹复制界面绘制说明.md) 和后续 UI 绘图使用。

本票据确定主页面的区域安排、窄窗口适配、空状态、选择与复制控件、设置分组和验证提示，以及操作反馈的视觉位置。历史列表展示范围与排序由 [issue 33](33-history-list-scope-and-order.md) 决定；设置数据库读写失败的状态行为由 [issue 34](34-settings-persistence-failure-feedback.md) 决定。

## 答案

### 主页面布局

- UI 绘图的默认画布为 1280×800；这只是设计基准，不设为硬性最小窗口尺寸。
- 页面标题使用“文件夹内容复制”；顶部工具区还放置选择文件夹、最近路径、当前路径和设置按钮；搜索输入框单独占一行。
- 主工作区采用左右分栏：文件树约占三分之二，辅助面板约占三分之一。辅助面板提供“当前选择”和“复制历史”两个视图，首次进入时默认显示“当前选择”。
- 页面底部固定显示已选文件数量及复制按钮。
- 复制按钮文案为“复制文件上下文包”。
- 窗口变窄、无法舒适显示左右分栏时，工作区改为“文件树 / 当前选择 / 复制历史”单面板切换；底部复制操作保持可见。

### 选择、空状态与复制反馈

- 没有选中文件时禁用复制按钮。
- 当前选择列表中的每个文件项提供直接移除操作；移除后同步更新文件树及已选数量。
- 分别为空文件夹/无符合规则文件和无历史记录的视图提供明确空状态。历史列表内容范围和排序见 issue 33。
- 复制成功后显示短暂成功提示。
- 普通复制失败时取消整次复制，并用对话框列出失败文件路径和可获得的原因。
- 从历史记录重读时若部分文件失败，继续复制成功文件，并提供可查看失败项的提示。
- 实时搜索不完整时在搜索区域显示提示，同时保留可访问结果；fd 不可用时在搜索输入框旁提示安装 fd。

### 设置弹窗

- 设置使用一个可滚动弹窗，按“文件白名单”“文件排除规则”“忽略目录”“大目录阈值”纵向分区。
- 每个分区提供独立的“恢复默认值”操作，只恢复该分区，不影响其他设置。
- 大目录阈值只接受正整数；空值、零、负数或小数在输入框旁显示错误，并禁用保存，直至输入有效。
- 设置数据库读写失败后的具体状态行为见 issue 34；本票据不改变其产品规则。
