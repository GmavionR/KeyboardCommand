# 确定文件扩展名白名单的默认策略

Type: grilling
Status: resolved

## 问题

默认应包含哪些文件扩展名？白名单设置对整个应用生效，还是可以按文件夹分别配置？

## 答案

白名单在整个应用范围内共用，并允许用户编辑。默认覆盖常见源码、配置、文档和脚本文本。敏感文本文件（如 `.env`、`.npmrc`、`*.pem`、`*.key`）可作为普通白名单文件纳入，不设置不可覆盖的敏感文件黑名单，也不扫描文件内容。二进制文件不纳入默认白名单；明显的锁文件和生成产物采用默认排除规则。用户可配置单独的文件名/路径排除规则，并在白名单之后应用。具体清单见 [issue 21](21-default-extension-list.md)，排除规则的匹配与呈现见 [issue 29](29-file-exclusion-rules.md)。
