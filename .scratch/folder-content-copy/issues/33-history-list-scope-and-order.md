# 确定历史记录列表的范围和排序

Type: grilling
Status: resolved

## 问题

历史记录全局最多 20 条，同一文件夹可以有多条；本票据确定历史面板的显示范围、排序和空状态。

## 答案

- 选择文件夹后，历史面板默认只显示该文件夹的记录，并可切换到“所有文件夹”查看全部历史。尚未选择文件夹时默认显示全部历史。
- 所有显示范围均按创建时间从新到旧排列。复制已保存快照不会刷新创建时间；从历史记录成功重读并替换后，新记录按新的创建时间排在前面。
- 当前文件夹没有历史时显示“此文件夹暂无复制历史”，并提供切换到“所有文件夹”的入口。
- 所有文件夹都没有历史时显示“暂无复制历史记录”，并提示用户选择文件夹、复制文件后历史会出现在这里。
- 历史面板的筛选范围不影响加载文件夹时的选择恢复：仍按该文件夹最新历史记录恢复符合当前筛选规则的文件，见 [issue 07](07-history-cardinality.md) 和 [issue 10](10-filter-changes-and-saved-selection.md)。

## Comments

- 用户确认上述显示范围、默认筛选、排序和空状态。
