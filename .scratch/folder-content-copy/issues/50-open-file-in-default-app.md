## Question

文件树如何双击文件用系统默认程序打开该文件？

## Answer

在文件树双击有效可选文件节点，用操作系统登记的默认程序打开该文件（等同资源管理器双击文件的语义）。目录节点、忽略目录和排除节点的双击不打开程序。

实现复用项目已有的 Tauri Opener 插件：前端调用 `openPath(绝对路径)`，与 issue 37 的“在文件资源管理器中显示”共用同一插件和 `opener:allow-open-path`（含 `**` 路径 scope）权限，不新增 Rust 命令，也不引入注册表或 `ShellExecute` 手搓代码。绝对路径的拼法沿用 issue 37 已有写法：根目录去掉尾部斜杠 + `\` + 节点相对路径中的 `/` 转 `\`。

手势冲突的处理：本树的行单击是“切换勾选”（issue 40 决定），而不是资源管理器那种幂等的“选中”，所以同一次双击必然先触发两次勾选切换。业界（VS Code、资源管理器）不出现闪动是因为它们的行单击只改选中态，没有可反转的切换语义，无法照抄。这里采用“单击延后一个双击判定窗口执行”的标准做法：文件行的勾选切换在 250 毫秒后执行，期间若收到双击就取消，因此双击只打开文件，勾选状态不变也不闪动；直接点勾选框、空格和 Enter 保持即时。目录行仍即时展开/折叠（不引入新延迟），落在勾选框、展开箭头、“加载更多”按钮上的双击只算快速切换选择，不拉起外部程序。打开失败只显示中文错误提示，不改动选择与展开状态。
