# 43：持久化并管理复制历史

**要构建：** 用户能查看和管理可恢复的复制历史；每次成功复制的快照在应用重启后仍可用。

**阻塞于：** [浏览真实目录并加载文件树](38-directory-tree-and-pagination.md)、[复制文件上下文包](42-copy-context-package.md)

**状态：** ready-for-agent
**标签：** ready-for-agent

**设计来源：** `playground/KeyboardCommand_Folder_Copy/docs/design.md` 的历史面板和交互是当前基准；持久化及恢复规则见 `.scratch/folder-content-copy/spec.md`、ADR-0001 和 ADR-0003。

- [ ] 每条历史由 `.meta.json` 元数据和 `.md` 正文配对保存；正文仅为完整上下文包。新增先写正文再发布元数据，删除先移除元数据，并清理孤立正文。
- [ ] 每次成功复制建立记录，保存创建时间、来源目录、文件数、文件列表和包快照；全局最多 20 条，按时间从新到旧显示，超限淘汰最早记录。
- [ ] 有当前目录时默认只显示该目录记录，可切换全部目录；没有当前目录时显示全部记录，并呈现设计规定的空状态。
- [ ] 复制历史快照不重读源文件、不刷新创建时间；“读取当前文件”逐项重读，部分失败时复制成功文件并替换当前记录，全部失败时保留旧记录和剪贴板。
- [ ] 删除历史后不可继续显示该记录；重新加载目录时仅恢复路径仍存在且符合当前规则的最新历史选择，失效项静默跳过。
- [ ] 逐条完成前，先运行 `ego-browser skill` 并用 ego-browser 检视 playground 历史面板和菜单；对照设计稿后，在桌面应用中手动验收重启持久化、筛选、快照复制、重读成功/部分失败/全失败、删除和恢复选择。
