# 44：接入系统设置与桌面能力

**要构建：** 用户能通过现有系统设置页面查看真实应用/存储状态，并使用设计中定义的主题和系统级行为控制。

**阻塞于：** [初始化桌面应用并接入现有页面](37-application-shell-and-ui.md)、[持久化文件规则设置](39-persist-file-rules.md)、[持久化并管理复制历史](43-history-storage-and-workflows.md)

**状态：** ready-for-agent
**标签：** ready-for-agent

**设计来源：** `playground/KeyboardCommand_Folder_Copy/docs/design.md` 的系统设置弹窗、标题栏及键位提示是当前基准；不得保留 mock 版本号、数据库状态或占用值作为正式数据。

- [ ] 系统设置提供跟随系统、浅色、深色三态主题；跟随系统时响应 Windows 明暗变化，选择结果在重启后保持。
- [ ] 版本、更新状态、SQLite 连接/模式/路径、应用数据占用和历史数量来自实际应用状态；SQLite 不可用时如实呈现错误状态。
- [ ] 按设计接入系统启动和桌面通知控制，并在操作失败时反馈；全局快捷键说明与实际生效快捷键一致。
- [ ] 更新检查不显示固定模拟成功状态；发行更新端点未配置时清晰呈现不可用状态。更新服务端、签名和发布通道部署不属于本票据。
- [ ] 逐条完成前，先运行 `ego-browser skill` 并用 ego-browser 检视 playground 标题栏、主题和系统设置交互；对照设计稿后，在桌面应用中手动验收主题持久化、真实存储状态和可用的系统控制。
