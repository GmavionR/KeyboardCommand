# 通过本功能设置弹窗读写 SQLite 配置

Type: grilling
Status: resolved

## 问题

本次功能必须通过真实界面操作走通 SQLite 查询和保存。决定哪些结构化数据由 SQLite 读写，例如最近文件夹路径、筛选设置、历史记录元数据或快照文件索引；同时明确哪些按钮触发查询、保存或删除，以及如何验收数据确实持久化。完整文件上下文包正文继续保存在文件快照中。

## 答案

本功能的设置弹窗承担 SQLite 读写验收流程：用户打开弹窗时，从 SQLite 查询配置；保存时，将扩展名白名单、文件名/路径排除规则、忽略目录和大目录阈值等设置写入 SQLite；保存完成后重新加载当前文件夹。重新打开弹窗仍能读到已保存配置。完整文件上下文包正文继续以文件快照保存。
