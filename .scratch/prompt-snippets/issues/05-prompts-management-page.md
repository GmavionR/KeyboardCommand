# 05：主窗口提示词管理页面（/prompts）

Type: task
Status: resolved
Label: ready-for-agent

## 要构建什么

在前端主窗口实现完整的 `/prompts` 管理页面：
1. 顶部操作栏：目录选择/变更、新建提示词、搜索过滤；
2. 提示词卡片列表：展示标题、触发词（command）、正文预览、更新时间；
3. 编辑弹窗/抽屉：标题、触发词、正文多行文本编辑；
4. 外部联动操作：在文件资源管理器中打开定位、在系统默认编辑器中打开；
5. 优雅容错展示（YAML 解析异常警告）。

## 验收条件

- [x] `/prompts` 页面功能完整，支持增删改查。
- [x] 外部修改后可刷新更新。
- [x] 界面与既有深浅色主题无缝融合。
